# Source-document review

## Assignment brief

The assignment requires: theoretical derivation of IM; 252-day price simulation; separate unlimited-cash and limited-cash/illiquid-asset default models; dealer loss distributions both unconditional and conditional on positive losses; fire-sale cost tracking; policy analysis for higher IM, weekly VM, shorter MPOR and eligible collateral; and a discussion of procyclical margining using a systemic liquidity externality.

## Submitted report

The Group 4 report covers these broad topics. It reports 100,000 paths over 300 trading days, baseline 1% annual PD, 10-day MPOR, $20,000 initial cash, $15,000 illiquid assets and 10% fire-sale discount. It presents policy comparisons and a regime-switching/systemic haircut extension.

## Submitted notebook

The uploaded notebook contains the original simulation, arithmetic Brownian motion, 99% IM calculation, exogenous defaults, limited-cash fire sales, dealer close-out losses and policy experiments. The revised implementation reorganizes the work into four notebooks with shared functions and explicit modelling conventions.

The submitted report and assignment PDFs are not included in this repository because the report includes group member names and student identifiers. This review intentionally omits those identifying details.
