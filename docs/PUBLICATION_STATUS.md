# Publication status

This branch contains the reorganized and anonymized presentation of the university group project. The submitted report PDF and assignment handout are not included because the report includes a group roster and student identifiers. The full submitted notebook is included with its original analysis content.

The corrected modular implementation and technical summary PDF were prepared locally during review, but only the original notebook and supporting methodology/results documentation are staged in this branch. The result tables describe the separately executed corrected implementation and should not be read as results generated by the notebook currently committed.

No licensed external market-data files are required or included. The simulation uses generated price paths and parameterized exogenous defaults.

No open-source licence is granted. The project is presented as collaborative academic work; contributor credits should be agreed by the group.
